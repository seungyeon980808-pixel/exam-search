# 얇은 도구 모음 · 2026-10-11

## 변경

- 검색·문항 상세·편집 화면의 기본 도구 모음을 높이 44px로 정리했다.
- 모바일 검색 목록에서 Hwp 변환을 상단에 유지하고 부가 설정과 선택 순서 관리를 더보기로 이동했다. 기존 DOM 컨트롤을 이동하므로 선택 상태와 이벤트를 공유한다.
- 상세 화면의 중복 검색/원본 도구 모음을 없애고 문항 정보·이동 및 이미지/PDF 기능을 팝오버에 모았다.
- 편집 화면의 문서 설정, 더보기, 저장, 닫기를 한 줄에 유지한다. 확대·원본 대조와 서식 도구는 더보기에서 접근한다.
- `한글로` 동작 이름은 `Hwp`로 바꿨다. 내려받는 실제 파일 형식은 HWPX다.
- 최초 모음 변환 클릭이 지연 로딩된 편집기의 이벤트 리스너보다 먼저 실행되던 문제를 수정했다.
- 추적용 쿼리만 붙은 첫 방문도 랜딩 화면을 표시한다. 과목/문항 딥링크는 그대로 열린다.
- 공유 모듈을 동일 릴리즈 키로 갱신해 이전 캐시와 새 PDF 경로 상태의 혼용을 방지했다.

## 한계

실제 iPhone 하드웨어 검수는 수행하지 않았다. WebKit 검사 중 외부 PDF 게이트웨이의 접근 제어 경고가 발생했지만 기존 대체 경로를 통해 문서 변환·다운로드·재파싱은 완료됐다. 이번 변경은 UI 및 변환 진입 문제를 다루며 기존 PDF 복원 정확도를 새로 보장하지 않는다.

## Safari 후속 확인

고해상도 PDF 렌더링의 10초 제한이 발생할 때, 정상 표시 중인 카드 이미지에도 내부 취소 오류를 노출하던 처리를 수정했다. 미리보기는 유지하고 PDF 원본 안내로 전환한다. PDF 요청 실패를 강제로 주입한 `node tools/qa-preview-failure.mjs`로 이미지 유지와 로딩 해제를 확인했다. 분할 미리보기 토글이 뒤로 버튼의 아이콘을 긴 문자열로 덮어쓰던 문제도 함께 수정했다.
