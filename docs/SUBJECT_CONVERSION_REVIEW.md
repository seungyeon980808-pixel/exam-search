## 수정 결과

- 국어·수학·영어·사회탐구 확장 자료의 상세 조회 실패를 수정했다. 검색 결과에는 존재하지만 상세 조회에서 과목을 찾지 못하던 날짜 시작 문항 ID를 지원한다. 과목에 해당하는 상세 데이터만 읽는 기존 지연 로딩을 유지했다.
- 화학·지구과학에서 한글 문구가 분자와 분모인 분수의 가로선이 사라지던 문제를 수정했다. PDF에 실제 가로선과 밀접한 두 텍스트 행이 있는 경우에만 편집 가능한 네이티브 수식으로 복원한다. 표 테두리·밑줄·일반 문단을 분수로 추정하지 않는다.
- 표 셀의 긴 분수 옆 설명이 셀 밖으로 밀리는 경우 설명을 별도 셀 문단에 배치했다.
- 긴 문장형 분수 뒤의 설명이 짧은 낱말만 남기는 줄로 쪼개질 때 설명 전체를 다음 문단으로 이동하도록 보정했다. 내용과 수식은 유지한다.
- 실제 앱과 검수 도구의 모듈 버전을 맞추고 기존 푸터에 반영 시각 배지를 표시했다. 푸터 높이는 유지했다.

## 남은 한계와 반영 상태

- 이번 표본 검수는 모든 수록 문항의 무결성을 보증하지 않는다. 자동 검사의 통과도 전체 수학적 의미나 시각적 품질의 완전한 검증을 의미하지 않는다.
- 저장·재열기는 rHWP 코어로 검사했다. 설치형 한컴 한글에서의 최종 렌더링은 별도 확인이 필요하다.
- 원본의 옆으로 나란한 그림·표가 변환 결과에서는 세로로 배치되거나 줄바꿈이 달라질 수 있다. 작은 유전 정보·그림의 글자 크기는 추가 개선 여지가 있다.
- 사용 중 AI 서비스나 토큰은 필요하지 않는다. 원본의 글꼴·좌표·그리기 명령과 규칙으로 처리한다.
- 이번 변경은 로컬 작업 트리에 반영했다. 커밋·푸시·배포는 실행하지 않았다.
