# 과탐 Hwp 변환 · 5E 문항 틀 최신 엔진 · 2026-10-26

## 변경

- 과학탐구(물리·화학·생명과학·지구과학 Ⅰ·Ⅱ) Hwp 변환의 5E 문항 틀을 5E 1.7.0 최신 조판 엔진(5E 5e1a181a)으로 올렸다. 문항은 원본 B4 지면(단 폭 112mm, 본문 11.5pt·장평 95%·자간 −3%·줄 간격 145%)에 맞춰 조판된다.
- 수식
  - 흩어지던 분수를 하나의 분수로 되살린다: 한글 없는 짧은 분수(A＋C/T＋G, 7/5), 분자·분모에 첨자가 든 분수, 〈보기〉 안 분수.
  - 질량수 같은 앞 첨자(ᵇX, ᵐ⁺²X), 본문 글꼴 아래 첨자(X₁, d₁, t₂), 이온 전하(OH⁻), 별표 위 첨자(B*)를 제자리에 둔다.
  - 단위(0.2 m, km/s, mol)·실제 원소 화학식(KCl, H₂O, Ca²⁺)·약어(LED, ATP, pH)는 바로 선 글자로, 변수·가상 원소(X, Y, 3m의 m)는 기울인 글자로 둔다.
  - 수식 안 띄어쓰기와 분수 속 한글 띄어쓰기를 살린다.
- 그림·표 배치
  - 원본에서 나란한 표·그림은 나란히, 글 옆 자료는 글 옆에 둔다. 자료와 범례 표를 함께 띄우고, 표 윗변에서 시작한 긴 발문은 표 아래에서 단 폭으로 넓어진다.
  - 자료가 여럿인 문항에서 한 장으로 잡힌 그림을 원본처럼 따로 넣는다.
  - 선지가 그림 옆에 오는 문항은 원본처럼 그림 옆에 둔다.
  - 실험 과정 항목 사이의 표, 과정 옆 장치 그림, 〔결론〕을 원본 순서대로 둔다.
  - 글줄 속 빈칸 상자(□, ㉠ 상자)에 테두리를 그린다.
  - 반응식 줄의 들여쓰기와 식 사이 간격을 살린다.
- 조판 안정성
  - 문항이 둘째 쪽으로 넘어가던 문제, 상자 마지막 줄이 테두리에 잘리던 문제, 그림 옆 좁은 줄이 크게 벌어지던 문제를 고쳤다.
  - 선지가 칸을 조금 넘칠 때는 줄을 나누지 않고 자간만 좁힌다. 대응표 선지는 원본 배치(2묶음·3묶음)를 따른다.
- PDF 문서를 닫을 때 작업자가 남던 문제(pdf.js 6.3.289)와, 작업자가 한 번 실패한 뒤 PDF가 열리지 않던 문제를 고쳤다.
- 바뀐 모듈은 캐시 키 `frame-20261025-1`로 올렸다.
