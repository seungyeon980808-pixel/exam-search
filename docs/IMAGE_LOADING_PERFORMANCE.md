# 문항 이미지 로딩 개선 검수 — 2026-10-10

목록에서는 전 과목의 문항 이미지와 시험지 썸네일을 사전 생성된 WebP로 표시한다. 확대와 HWPX 변환에는 기존 원본 PDF를 계속 사용한다. AI 호출은 추가하지 않았다.

## 병목과 변경

- 기존 과학탐구 8,420문항에는 정적 이미지가 있었지만, 국어·영어·수학·사회탐구 11,340문항은 브라우저가 PDF를 내려받아 문항을 만들었다. 공개 PDF 서버의 응답과 렌더 대기가 목록을 지연시켰다.
- 총 19,760문항과 822개 시험지에 정적 미리보기를 연결했다. 기존 과학탐구 이미지와 원본·검색 본문·변환 메타데이터는 보존했다. 추가 미리보기 파일은 약 396MiB이며 사용자는 보이는 문항과 인접 문항만 받는다.
- 화면 안 이미지부터 요청하며 이미지 요청은 4개, PDF 대체 렌더는 2개로 동시 처리 수를 나눴다. 화면 밖 대기와 이전 검색의 작업은 취소하고 제거된 카드의 이미지 URL을 해제한다.
- 파일명에 이미지 내용 해시를 포함하고 목록에 크기를 함께 제공한다. 검증된 목록 캐시를 사용하며 새 미리보기 정보가 적용되도록 캐시 버전을 갱신했다.
- WebKit은 이미지가 뜨기 전 대체 텍스트 높이를 사용하는 경우가 있었다. 이미지 영역의 비율을 명시적으로 예약해 로딩과 오류 전후 카드 위치를 유지했다.
- 미리보기 파일이 손상되면 기존 원본 PDF 렌더로 대체한다. 두 경로가 모두 실패해도 오류 안내와 문항 선택을 유지한다.

## 측정 조건

- 과학탐구: 물리학 I / 2025학년도 수능, 검색 결과 20문항.
- 사회탐구: 2026학년도 수능, 전체 세부과목 범위.

## 기능·품질 검수

- 자동 테스트 347개 통과. 전체 문항·시험지의 이미지 파일, 크기, 내용 해시, 색인 버전을 확인했다. 원본 문항 데이터와 상세 색인이 그대로 일치한다.
- 이미지 화면 검수 34개 시나리오 통과: Chromium·WebKit, PC 1440px·모바일 375px, 과학·사회·수학·국어·영어 목록과 시험지 썸네일, 화면 밖 요청 지연, 이미지 대기 중 선택, 빠른 스크롤 복귀, 늦은 과목 응답 차단, 손상 이미지 대체, 원본 고해상도 확대, 원본도 없는 오류 표시.
- 라이브러리 검수 9개 묶음 통과: 두 브라우저의 1440px·768px·375px 화면, 연도 범위·단원·페이지 전환, 검색 실패 재시도와 검색어 유지, 손상 캐시 복구, 12개 과목 검색 결과·순서 일치, 실제 HWPX 편집·내보내기와 미저장 작업 보호. 수식 7개를 보존한 문서를 다시 열어 확인했다.
- 국어·수학·영어·사회탐구의 대표 문항을 보관된 원본 PDF에서 다시 렌더해 새 WebP와 내용 해시가 일치함을 확인했다.
- 최종 WebKit PC·모바일 스크린샷에서 이미지 비율, 제목과 버튼, 기존 Aurora Light 색상, 가로 넘침을 확인했다.

검수 자료는 로컬 `_work/image-performance/`에 있다. 이전·이후 측정은 `before.json`·`after.json`, 이미지 검수는 `ui/results.json`, 원본 대조는 `source-verification.json`, 캐시 반복 검수는 `revisit-stress.json`에 기록했다. 일반 라이브러리 검수는 `_work/performance/ui/results.json`에 있다. 이 로컬 자료를 제품 사이트에 게시하지 않는다.

## 남은 범위

- 이 수치는 로컬 환경의 결과다. 배포 서버·저속 네트워크·실제 모바일 기기의 시간을 보장하지 않는다. 원본 확대·한글 변환은 계속 공개 PDF 서버의 응답 영향을 받는다.
- 기존 문항 경계·공통 지문·짝홀형 중복과 변환 품질 자체를 이미지 생성만으로 검증한 것은 아니다. 이번 작업은 원본과 기존 크롭 결과를 보존하는 로딩 개선이다.
- 최종 비율 조정 후 첫 측정 시도에서 재방문 목록 준비가 한 번 30초 제한을 넘었다. 원인 자료가 남지 않아 원인은 미확정이다. 최종 20회 속도 측정과 추가 20회 연속 캐시 재방문에서는 재현되지 않았고, 추가 재방문의 목록 준비 최댓값은 118ms였다. 재현 시 화면 상태·실패 요청을 저장하도록 측정 도구를 보강했다.
- 위 측정과 검수는 로컬 작업 트리에서 진행했으며, 당시에는 병합·푸시·배포를 실행하지 않았다. 2026-10-10 사용자의 배포 요청에 따라 Aurora Light UI와 함께 공개 배포를 준비했다. 재방문 시 이전 검색 모듈·색인 캐시를 사용하지 않도록 모듈 주소 버전과 목록 캐시 버전을 갱신했다.
